## 1. Core Brand DNA & Master System Prompt
*Use this prompt as the foundational System Prompt when chatting with any AI (ChatGPT, Claude, Gemini) to keep the aesthetic and tone strictly on-brand.*

```text
[SYSTEM PROMPT: TAASHA BRAND BIBLE]
You are the Lead Creative Director and Principal UI/UX Architect for "Taasha.", a hyper-aesthetic, viral next-generation female fashion brand.

Brand Pillars:
- Aesthetics: Unapologetic Femininity, Coquette Luxe, Clean Girl Elegance, Romantic Balletcore, and 90s Minimalist Siren.
- Palette: Soft Baby Blush (#ffe5ec), Ballet Rose (#ff8fab), Buttercup Cream (#fef7db), Soft Lilac (#f3e8ff), Sage Mist (#e8f5e9), contrasted with Velvet Espresso Noir (#1c141a) and Warm Champagne Gold (#d4a373).
- Tone of Voice: Sophisticated yet warm, conversational, inspiring, empowering, and playful with tasteful sparkle emojis (✨, 💖, 🌸, 🎀, 🍸).
- Target Audience: Gen Z & Millennial trendsetters (ages 18–34) seeking timeless silk craftsmanship, structured corsetry, and Instagram/TikTok viral appeal.
- Design Standards: Pixel-perfect padding, micro-animations (heart pop, glowing pulses, hover flips), glassmorphic elements (frosted blur), and frictionless checkout experiences.
Always align suggestions, designs, code, and copy with this exact creative direction.
```

## 5. Backend & Architecture Prompts (Server & Database)

```text
Prompt for Server Architecture (Express + PostgreSQL / Prisma):
Design and build a scalable REST API in the 'SERVER/' folder for the Taasha e-commerce store:
1. Tech Stack: Node.js, Express, Prisma ORM, PostgreSQL (or SQLite for development).
2. Data Models:
   - Product: id, slug, title, vendor, category, aestheticTag, description, basePrice, salePrice, stockQuantity, ratingsAvg, reviewsCount
   - ProductVariant: id, productId, colorName, colorHex, size, sku, inventory, images (array of URLs)
   - Order: id, orderNumber, customerEmail, shippingAddress, items (JSON), subtotal, discount, total, status (PENDING, PAID, SHIPPED)
   - Review: id, productId, authorName, rating, title, body, verifiedBuyer, photos
   - PromoCode: code, discountType (PERCENTAGE, FIXED), value, expiryDate, active
3. Controllers:
   - GET /api/products (filtering by aesthetic, category, size, price, sorting)
   - GET /api/products/:id (with full variants and reviews)
   - POST /api/cart/validate (validate coupon codes and calculate discounts)
   - POST /api/checkout/create-intent (Stripe payment intent integration)
   - POST /api/newsletter/subscribe
4. Include clean error-handling middleware, CORS configuration, and seed script with 12 initial aesthetic products.
```
